# Dotfiles

作業環境の基礎を定義する Nix Flake であり、エディタや Git などのツール群をまとめているもの。<br/>
特定の言語などを開発するための環境ではなく、それらの基礎となる環境として整えています。

また `home-manager` 等は使っておらず、`nix develop` などで適用することを前提に作られています。
